# Project Roadmap
## Phase 1 — Documentation
- Document discrete math foundations
- Document Bigtable concepts
- Create architecture diagrams
- Define initial business use cases
## Phase 2 — Sensor Prototype
- Connect Raspberry Pi or ESP32
- Capture temperature and humidity
- Add timestamps and equipment identifiers
- Store observations locally
## Phase 3 — Cloud Data Pipeline
- Build ingestion process
- Design Bigtable row keys
- Create column families
- Send telemetry to Bigtable
## Phase 4 — Analytics
- Implement threshold detection
- Calculate trends
- Detect abnormal readings
- Generate alerts
## Phase 5 — AI / ML
- Build feature-engineering pipeline
- Train anomaly-detection models
- Explore predictive maintenance
- Compare rule-based and ML-based detection
## Phase 6 — Product Prototype
- Build dashboard
- Add notifications
- Create customer/device configuration
- Package the platform as a demonstration or proof of concept

## Long-Term Goal

The long-term goal is to develop a reusable IoT analytics platform that can
collect operational telemetry, detect abnormal conditions, and provide useful
alerts or predictions for real-world equipment and facilities.
